# Ministry of Labor Mini-App

🔗 Live demo: https://ministry-of-labor-miniapp.uiux-asmaa-a.workers.dev/

> Runs in demo mode with sample data — not official ministry data.

Svelte 5 + Vite 7 + TailwindCSS 4 + TypeScript, RTL Arabic UI.

## Run

```bash
npm install
npm run dev:mol
npm run build:mol
```
